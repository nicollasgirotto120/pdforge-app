# PDForge

> Practical PDF tools designed for fast, private mobile workflows.

PDForge is an independent product developed by **Nicollas Girotto** at **NG Labs**. It makes common PDF tasks accessible on Android without forcing users into a complicated desktop workflow.

## Key features

- Merge multiple PDF files
- Split PDF documents
- Compress PDF files
- Convert images to PDF
- Organize output files
- Local processing for supported tools
- Offline use for local operations

## Technology

`Flutter` · `Dart` · `Android` · `PDF processing` · `Local file handling` · `AdMob` · `Git`

## Product and engineering work

The project covered file selection, PDF processing flows, result handling, mobile UX, advertising integration, testing, release signing and store publication preparation.

### Main decisions

- **Privacy-oriented processing:** supported PDF operations happen locally.
- **Task-focused UX:** each tool follows a direct choose-process-result flow.
- **Mobile-first output:** generated files are organized for quick access and reuse.
- **Release readiness:** the Android build was audited, signed and prepared for Google Play.

## Status

**Android v1.0.0 — technically complete and ready for publication.**

## Repository scope

This public repository is a product showcase. The production source code, signing files, credentials and user files remain private.
